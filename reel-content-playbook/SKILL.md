# Reel Content Playbook

Turns any idea into a ready-to-post short-form video or carousel, using methods from creators who consistently reach 100k to 2M+ views. It works for any topic and any brand, because the brand comes from the user's own brand profile, never from this file.

Reply in the language the user writes in. Never use em dashes in any copy you write.

## Step 0: Load the user's brand (always first)

Every post must sound and look like the user, so check for a brand before writing anything:

1. **A brand guide skill exists** (any skill whose name or description mentions brand, style guide or voice): load it and use it. It overrides the defaults in this file.
2. **`brand-profile.md` in this skill's folder is filled in** (it has no `[brackets]` left): use it.
3. **Neither exists:** run the brand setup below before the first post. Keep it short: one message with the questions, accept partial answers, and use sensible defaults for anything skipped.

### Brand setup questions

Ask these in one message, in the user's language:

1. **Name and handle:** what is the account called, and which handle shows on posts?
2. **What you do and for whom:** one sentence about you and who your audience is.
3. **Language:** which language do you post in? (One per platform if it differs.)
4. **Voice:** 3 words that describe how you sound (e.g. warm, direct, funny), plus words or phrases you never use.
5. **Colors:** your brand colors as hex codes (main, text, background, accent). Say "no brand colors yet" and we use neutral ones.
6. **Fonts:** heading font and body/label font. Optional.
7. **Content pillars:** the 3 to 4 themes you post about. If you don't know, use the defaults in section 3.
8. **Things to avoid:** topics, styles or claims that are off-limits (e.g. hard selling, slang, medical advice).
9. **Call to action style:** do you send resources by DM ("Comment WORD"), put the resource in the post, or ask people to save or follow?

Then write the answers into `brand-profile.md` if the environment can save files, and show the user the filled profile so they can correct it. If files cannot be saved, give them the filled profile to keep and paste next time.

## Default output: the post package

When the user gives an idea, a topic, a link or a rough thought, deliver this package unless they ask for only one part:

1. **Pillar:** which content pillar it belongs to, and one line on the angle that makes it theirs.
2. **3 hook options:** at least one built with the Triple Hook Method and at least one from the proven templates. Label which is which.
3. **Script:** written to be spoken, short sentences, in their voice. Mark the context, lean and snapback beats. Default structure:
   - Hook (context, lean, snapback) in the first 1.5 seconds
   - 3 numbered points, one idea each
   - "The bad part": one honest downside or limit (it builds trust)
   - Soft close and CTA
4. **On-screen text plan:** key overlays with timing and placement (section 4), in the brand fonts and colors.
5. **First-second visual:** one concrete idea to grab attention visually (section 5).
6. **Caption:** short first line, 2 to 4 short lines, one question to the reader, the CTA, then a few hashtags.
7. **CTA:** following the brand's CTA style (section 7).

Then offer one natural next step: a carousel version, another language, or a batch of related ideas.

### Carousel version

When the user asks for a carousel (or the idea fits one better):

- Slide 1 is the hook: one big line with context and curiosity.
- One idea per slide, few words, in brand fonts and colors.
- Match each slide's photo or visual to exactly what that slide says.
- Include the resource itself in the carousel when possible, so the post is useful without a DM.
- Last slide: soft close (save, share, or the brand's CTA).
- Keep it about the reader, not about the creator.

## Other ways to use it

- **"Review this script / video":** run the review checklist at the end. Quote the exact line or second that fails, and give a fix.
- **"Plan my posts":** a batch of ideas, each tagged with its pillar, balanced across the week.
- **"Give me hooks for X":** 5 to 7 hooks, mixed between the Triple Hook Method and the templates.
- **Topics outside the user's expertise** (health, beauty treatments, finance): frame them as personal experience or point of view, never as expert advice.

## 1. The Triple Hook Method

A hook has three beats, in order, within the first few seconds.

1. **Context.** The first line says what the video is about, in audio AND on-screen text. People only watch topics they have a stake in; unclear context is the main cause of skips.
2. **Lean.** Create curiosity in one direction: a stat that validates the promise, a specific pain point, a specific benefit, or something surprising. The viewer must lean in instead of opting out.
   - Test: read the first 1 to 2 sentences alone. Is the context instantly clear? Is there a reason to keep watching?
3. **Contrarian snapback.** Once the viewer leans one way, say something that pulls them the opposite direction (like pulling a fishing line the other way to set the hook). Most creators skip this, and it is where retention is won.

## 2. Proven hook templates

Fill the brackets with the real topic.

| # | English | Español |
|---|---------|---------|
| 1 | "Is it possible to [goal] in a really [short time]?" | "¿Es posible lograr [objetivo] en muy [poco tiempo]?" |
| 2 | Say the exact time out loud: "It's exactly [time] and I just promised myself I'll [goal] before [deadline]." | "Son exactamente las [hora] y acabo de prometerme que voy a [objetivo] antes de [fecha límite]." |
| 3 | "I don't know who needs to hear this, but..." | "No sé quién necesita escuchar esto, pero..." |
| 4 | "[Number] days ago, I..." | "Hace [número] días, yo..." |
| 5 | "This is how you can [result]. And I know what you're probably thinking..." | "Así es como puedes lograr [resultado]. Y sé lo que probablemente estás pensando..." |
| 6 | "If you've been [frustrating or painful situation]..." | "Si has estado en [situación frustrante o dolorosa]..." |
| 7 | Give a controversial opinion, then say "I'll go first." | Da una opinión polémica y luego di "Empiezo yo." |

**Never open with a topic announcement** ("Today we're going to talk about..."). Open with the viewer's specific problem: "If you're getting leads but none of them buy, you're probably solving the wrong problem."

## 3. Content pillars

Having many interests is not the problem; posting them without structure is. Use the pillars in the user's brand. If they have none, use these four, so every post builds one recognizable person:

- **Lifestyle:** who you are
- **The build:** what you are making or working on
- **Mindset:** how you think
- **Creative identity:** what makes your perspective yours

Any topic can fit a pillar, so the feed reads as one person instead of many random topics.

## 4. On-screen text

- Text placement decides where the viewer looks first. Use it on purpose.
- Never cover the subject (face, product, screen) with captions. Put text in empty space.
- To make the viewer notice something specific, place text right next to it.
- Keep text inside the safe area: the top 11%, the bottom 22% and the right edge are covered by app buttons on Reels and TikTok.
- Pair one big word with a small supporting line, in the brand fonts. Avoid default editor fonts and neon captions unless they are part of the brand.

## 5. First-second visuals and editing

**Freeze frame opener (CapCut or any editor):**
1. Find a moment with big movement and cut the clip right there.
2. Screenshot that frame and drop it on the timeline.
3. Duplicate it into two layers. Top layer: remove the background. Bottom layer: pull brightness all the way down.
4. Place a title between the two layers so the subject sits in front of the text.

**Text behind the subject:** a huge word placed behind the person (they stand in front of the letters). Strong for hooks and titles.

**Floating UI cards:** screenshots, app screens or profile cards sliding in over a calm background on the beat.

**Paper collage animation (AI):**
1. Generate a strong first frame with an image model. Do not ask for "a cartoon"; describe the exact style, e.g. "2D paper collage, layered cut paper, one piece on top of another".
2. Send that frame to an image-to-video model with a prompt describing exactly what should happen.

**Effects worth knowing:** air marker (drawing in the air), screen dive, finger tags (labels on raised fingers), face lock, hand frame, pocket proof (a photo pulled from a pocket), clap wave, ball toss, rewind.

## 6. AI-assisted motion that doesn't look like AI

- AI tools don't know motion design by default. Give them motion principles (easing curves, timing, anticipation, overshoot) and the animation becomes natural.
- AI-made sound effects sound fake. Give the tool a real sound library (whoosh, pop, soft impact, mouse click) and let it choose.
- AI fakes interfaces. Record the real interface with a screen recorder instead.
- Rule: **outsource execution, never creative direction.**

## 7. CTA

Follow the CTA style in the user's brand. The main options:

- **Comment to DM:** "Comment [WORD] and I'll send you [resource]." Use one short, on-topic keyword, say it on video and repeat it in the caption. The resource must be free and genuinely useful (a list, template, guide or link). It needs a DM automation tool (e.g. ManyChat) to work at scale.
- **Resource in the post:** put the list or template in the carousel or caption itself, and ask people to save it.
- **Save, share or follow:** "Save this for when you..." is a soft close that fits almost any brand.

Do not use the same CTA on every post. Never fake urgency, never hard-sell, never promise something that isn't real.

## Review checklist

Check each item and quote the exact line or timestamp that fails, with a fix:

- [ ] On brand: voice, words, colors and fonts match the brand profile
- [ ] First line sets context in audio AND on-screen text
- [ ] There is a clear lean (stat, pain, benefit or surprise)
- [ ] There is a contrarian snapback
- [ ] The opening is not a topic announcement
- [ ] Something visual grabs attention in the first second
- [ ] On-screen text never covers the subject, guides the eye and stays in the safe area
- [ ] The post maps to a content pillar
- [ ] There is an honest "bad part" or limit
- [ ] AI-made motion uses real motion principles, real sounds and real UI
- [ ] One clear CTA that fits the brand, and not the same one as the last post
- [ ] No em dashes in any copy
- [ ] Every claim and number is real
